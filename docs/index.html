Install

Browser -CDN (jsDelivr) 
<script src="https://cdn.jsdelivr.net/gh/memoriainfinita/notae@master/dist/notae.js"></script>
<script>
  const svg = Notae.renderFretboard({
    name: 'Cmaj7',
    frets: [0, 3, 2, 0, 0, 0],
    fingers: [0, 3, 2, 0, 0, 0],
    tuning: ['E', 'A', 'D', 'G', 'B', 'E'],
  });
  document.getElementById('chord').innerHTML = svg;
</script>

API

Function Chord type Returns
Notae.renderFretboard(chord, style?) FretboardChord SVG string
Notae.renderPiano(chord, style?) PianoChord SVG string
Notae.renderBowed(chord, style?) BowedChord SVG string

All renderers accept an optional StyleOptions object -colors, sizes, fonts, filter effects, orientation, and more. Full type definitions and defaults at github.com/memoriainfinita/notae.
